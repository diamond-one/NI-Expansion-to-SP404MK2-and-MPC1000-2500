# Kit workshop

A native Windows tool for a musician to turn installed Maschine expansion samples into playable SP-404MKII kits and MPC1000 / JJOS3 programs, and to build kits from loose samples. The main task is auditioning and replacing individual sounds before exporting.

The user wants direct conversion without recording. Synths, effects and EQ are not rendered. An NI original demo is an audition reference, independent of edited pad sounds. The app must make unresolved sounds easy to replace and must not lose edits when browsing, switching workspace modes or changing MPC banks.

MPC programs contain four independent 16-pad banks A–D. SP export uses the current 16-pad bank; sending to hardware retains destination and overwrite review. Optional MIDI triggers computer audio for immediate audition. Folder and file operations preserve original NI content.

The user explicitly requested Neo-Brutalism on 17 October 2026, with a more considered Play & export / Batch export interface. This replaces the previous charcoal/gold visual system. This is an instrument workspace, used for repeated listening beside hardware, with legibility and a predictable pad layout taking priority over decoration.
