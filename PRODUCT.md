# Kit workshop

A native Windows tool for a musician to turn installed Maschine expansion samples into playable SP-404MKII kits and MPC1000 / JJOS3 programs, and to build kits from loose samples. The main task is auditioning and replacing individual sounds before exporting.

The user wants direct conversion without recording. Synths, effects and EQ are not rendered. An NI original demo is an audition reference, independent of edited pad sounds. The app must make unresolved sounds easy to replace and must not lose edits when browsing, switching workspace modes or changing MPC banks.

MPC programs contain four independent 16-pad banks Aâ€“D. SP export uses the current 16-pad bank; sending to hardware retains destination and overwrite review. Optional MIDI triggers computer audio for immediate audition. Folder and file operations preserve original NI content.

The user chose the Punk prototype on 18 October 2026. Paper strips, black outlines, condensed Oswald headings, acid selected pads and lavender navigation carry the style. This is an instrument workspace for repeated listening beside hardware; readable sound names, retained edits and a predictable pad layout take priority over decorative effects.
